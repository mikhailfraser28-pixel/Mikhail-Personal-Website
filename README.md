# Mikhail-Personal-Website
A website with a little information about me
this is a website made by mikhail fraser. it is a a website with a bit of personal infomatiom

this is my personal website created using HTML5, CSS3, JavaScript, and GitHub. The website contains information about me, my interests, skills, projects, and contact information.

JavaScript Features
The website includes five JavaScript features:

1. Dark/Light Mode
   Allows users to switch between a light and dark website theme.

2. Digital Clock
   Displays the current time and updates every second.

3. Character Counter
   Counts the number of characters entered into the contact message box.

4. Dynamic Table Row
   Allows a new skill to be added to the skills table using JavaScript.

5. Contact Form Values
   Retrieves the name and email entered by the user and displays the information.
